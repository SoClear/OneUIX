# 三星键盘双拼实验（Issue #21）

## 实验范围

开关为“启用双拼（实验性）”，沿用 `unlockKeyboardShuangpinLayout` 配置键，默认关闭。需要将三星键盘 `com.samsung.android.honeyboard` 加入 OneUIX 的 Xposed 作用域，修改设置后重启键盘进程。

### 第一轮：只放开布局

DexKit 通过 `boolean (Language, String)` 签名和 `shuangpin_qwerty` 字符串定位布局过滤方法；5.9.40.48 对应 `Vg.a.b`。结果必须唯一，配置缓存按宿主 versionCode 失效；不匹配则记录日志并跳过。只为 `shuangpin_qwerty` 返回可用，其他布局保留原逻辑。

Issue 反馈：5.9.40.48 的双拼已可选择，但选择后无法打字。第一轮只能证明布局过滤已生效，不能证明引擎输入可用。

### 第二轮：补齐 5.9.40.48 的 XT9 双拼输入路径

输入适配器 **只针对 versionCode 594048300**，采用该 APK 中经静态检查的类名、成员名和完整签名，运行时先验证绑定再安装；失败时回滚输入 Hook，保留布局解锁并记录错误。不将这套混淆绑定用于其他版本。

在当前布局为双拼时补齐以下路径：

1. `xt9.i.a(int)`：简体中文语言 225 的键盘数据库由 `0x0de1` 改为双拼分支的 `0x0fe1`。已经正确的数据库、其他语言和九键路径保持不变。
2. `Xt9Wrapper.r1(int)`：允许 XT9 双拼声母/韵母内部符号（62000–62026、62032–62065），其他输入走原逻辑。
3. `xt9.g.a()`：从原生拼写缓冲区还原声母/韵母，并沿用宿主映射及非双拼符号的转换规则。不能只处理原返回值，因为 `P1=false` 时通用格式化器可能已经丢弃私用区符号。
4. `XT9KeyboardDatabase.processElseKey(...)`：只为没有文字标签的双拼符号键恢复原 `u1=true` 分支的数组式按键构建，保留占位键、普通文字键和九键行为。

这些适配 **不修改 `d9.a.P1` / `d9.a.u1` 全局字段，不临时切换地区，也不替换输入引擎**。对已支持双拼的路径尽量保留原结果。相关 AOT 内联调用方进行定向反优化。

双拼方案设置页仍可能隐藏；本实验不解锁搜狗多套方案。底层词库或原生引擎是否支持仍须由故障设备验证，不能因静态代码或单元测试通过就宣称已修复。

## 验证与诊断

1. 安装第二轮 OneUIX APK，保留/打开双拼实验开关，确认三星键盘作用域，重启键盘。
2. 检查模块日志：
   - `Shuangpin layout filter hooked`：布局过滤 Hook 安装成功。
   - `XT9 Shuangpin input adapter installed for 5.9.40.48`：四个输入 Hook 安装成功。
   - `XT9 Shuangpin active; P1=..., u1=...`：实际进入双拼路径；仅安装日志不表示已进入 XT9。
   - `keyboard database corrected: 0xde1 -> 0xfe1`、`symbol validation enabled`、`symbol key construction enabled`、`spelling conversion enabled`：相应修正已实际执行。
3. 原生诊断会限次记录 `ET9CPSetInputMode(3)`、`ET9CPLdbInit(225)`、`ET9KDB_SetKdbNum(4065)` 的返回状态（0 通常表示成功）。非 0 不会被伪装成成功，可用于继续定位原生引擎/词库问题。
4. 记录按键后有无拼写、有无候选词、候选词能否上屏、重启后是否保留布局；切回普通拼音、九键、英语，确认行为未改变。
5. 若仍然失败，请提供从重启键盘到复现后的 OneUIX 模块日志。没有进入 XT9 的日志时需进一步确认实际引擎；不要盲目继续打开其他地区功能。
6. 关闭开关并重启键盘可恢复原逻辑。

诊断只记录路径、功能开关、数据库/模式编号及原生返回码，不记录按键符号、拼写、候选词或用户输入文本。

正常对照手机为 BRI / Taiwan、5.9.40.78：版本和地区均与故障环境不同，不能作为 5.9.40.48 国际地区适配成功的证明。不要为了验证而直接替换手机的系统键盘 APK。

## 本地验证

- `:app:assembleDebug` / `:app:assembleRelease`：编译、打包及 R8。
- `:app:testDebugUnitTest`：配置默认关闭、旧配置读取及序列化兼容性。
- `:hook:testDebugUnitTest`：数据库修正边界、符号范围、占位/九键/非双拼保护、从原生缓冲区进行拼写转换、无声母音节及非双拼符号回退。

单元测试不验证 Xposed 回调、反射绑定和原生引擎运行时行为。第二轮仍需 Issue 反馈者在 5.9.40.48 故障设备上验证。
